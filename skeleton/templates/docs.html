Unit Converter API Documentation

Endpoint Expects Returns
/ Nothing Status 200 with the service name and "running"
/temperature value: a number
from: C or F
to: C or F 		Status 200 with the original value, units, and converted result.

Status 400 if the request is invalid.
/docs Nothing This documentation page.

Examples

Temperature Conversion

Example request: 

/temperature?value=32&from=F&to=C

Successful response: 

{
    "value": 32,
    "from": "F",
    "to": "C",
    "result": 0
}

Invalid requests return HTTP status 400.
